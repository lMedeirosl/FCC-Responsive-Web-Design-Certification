HTML Basics

HTML is the standard markup language for creating web pages.

It structures content using elements like headings, paragraphs, and links.

<h1>Hello World</h1>

  • Has semantic meaning
CSS Fundamentals

CSS is used to style and layout web pages.

It controls colors, spacing, fonts, and positioning.

body { color: black; } h1 { font-size: 24px; }
  • Selectors
  • Properties
JavaScript Essentials

JavaScript adds interactivity to web pages.

It can manipulate the DOM dynamically.

console.log("Hello");
  • Variables
  • Functions
Responsive Design

Responsive design adapts layouts to different screen sizes.

It improves usability across devices.

@media (max-width: 600px) {}
  • Mobile first
Debugging Tips

Debugging helps identify and fix errors in code.
